# 部署说明

本文件是**通用模板**：所有 IP、端口、别名都是占位符，替换成你自己的即可。
真实的服务器地址与口令见仓库根目录 `开发指南.md`（该文件已被 `.gitignore` 排除，不会公开）。

## 服务器事实（示例）

- 免密登录：先在本机 `~/.ssh/config` 里加一段别名，然后 `ssh <你的别名>`
  ```
  Host classcheckin
      HostName <公网IP>
      Port 22
      User root
      IdentityFile ~/.ssh/<你的私钥>
  ```
- 系统：Debian 12 bookworm / 2 核 / 4GB / 26GB 可用 / Python 3.11.2
- 无 iptables / nftables / ufw（入站只靠控制面板的 NAT 端口映射）

## 端口映射

| 用途 | 外网端口 | 内网端口 | 协议 | 说明 |
|---|---|---|---|---|
| 签到系统（HTTP + WebSocket） | <外网端口> | 18100 | TCP | 只需要这一条 |
| 闲置 | <随便> | 18101 | TCP+UDP | 当前没有服务占用，可删可留 |

> 面板的“自定义”类型 = 同一个外网端口同时转发 TCP 和 UDP。
> 本系统 HTTP 与 WebSocket 都跑在 TCP 上，**只需要 TCP**。
> UDP 映射对本项目没有用处。
> 想换端口，只要改 `/etc/systemd/system/class-checkin.service` 里的 `CHECKIN_PORT`
> 并把面板映射的内网端口指向它即可。

## systemd 服务

```bash
systemctl status class-checkin
systemctl restart class-checkin
journalctl -u class-checkin -n 50        # 或直接看 /opt/class-checkin/data/server.log
```

服务文件：`/etc/systemd/system/class-checkin.service`

```ini
[Service]
WorkingDirectory=/opt/class-checkin/server
Environment=CHECKIN_PORT=<内网端口>
Environment=CHECKIN_DATA=/opt/class-checkin/data
Environment=CHECKIN_WEB=/opt/class-checkin/web
ExecStart=/usr/bin/python3 /opt/class-checkin/server/app.py
Restart=always
```

## 首次部署做了什么

1. 打包本地 `server/ web/ tests/ tools/` 上传到 `/opt/class-checkin`
2. 写 systemd 单元并 `enable --now`
3. 首次启动自动建库并生成初始账号，写入 `/opt/class-checkin/data/初始账号.txt`
4. 用 `tools/provision.py` 批量开号（名单示例见 `docs/账号表.example.csv`）

## 更新

```powershell
# 改完代码后
D:\learn\class-checkin\deploy\redeploy.ps1              # 默认 ssh 别名 vanmc
D:\learn\class-checkin\deploy\redeploy.ps1 -Remote 别名  # 换成你自己的
```

脚本会重新打包、上传、解包、重启服务，并在最后打印服务状态。

## 备份与恢复

- 后台「高级 → 下载数据库备份」
- 或命令行：`scp <别名>:/opt/class-checkin/data/app.db .\backup.db`
- 恢复：把 app.db 传回 `/opt/class-checkin/data/` 后 `systemctl restart class-checkin`

## 排错

| 现象 | 检查 |
|---|---|
| 公网打不开 | `systemctl status class-checkin`、`ss -ltn \| grep <内网端口>`、面板映射是否生效 |
| 页面白屏 | 浏览器控制台；多半是某个 view 的模板报错 |
| WebSocket 连不上 | 反向代理若加了 Nginx 需转发 Upgrade 头；本项目直连无需额外配置 |
| 忘记管理员密码 | `ssh <别名>` 后运行 `python3 /opt/class-checkin/server/bootstrap.py`（仅当无用户时建号），或后台 SQL 控制台改 |
